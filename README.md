# Git gud. Продвинутое использование контроля версий

Лекция для ЛШ2025 по углубленному использованию git.

Основные темы:

- Стратегии ветвления кода в проекте
- Работа с удаленными репозиториями
- Работа с историей изменений
- Конфликты слияния в Unity
- git-lfs для видеоигровых проектов
